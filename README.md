# Projeto E-commerce
Landing page de tecnologia inspirada na Apple, com temática de Copa do Mundo e estilo Black Friday. O projeto simula uma loja virtual moderna e responsiva, onde usuários podem explorar produtos, visualizar ofertas e adicionar itens ao carrinho de compras de forma dinâmica e interativa.

## Funcionalidades

- Catálogo de produtos
- Busca dinâmica
- Filtro por categorias
- Carrinho de compras
- Tema claro e escuro
- Persistência com LocalStorage
- Finalização via WhatsApp

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Objetivo

Simular uma loja virtual moderna e responsiva para estudo de desenvolvimento Front-End.
